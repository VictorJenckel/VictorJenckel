## Projeto em destaque

### Industrial Data Gateway — Glass Inspection Lines

Sistema de engenharia de dados desenvolvido para ingestão e processamento de dados provenientes de linhas industriais de inspeção de vidro.

O projeto coleta dados das máquinas Eagle Vision (SL2, LRA1 e FSP), realiza tratamento, validação e deduplicação dos registros e disponibiliza os dados em **PostgreSQL**, utilizando **Apache Airflow** para orquestração dos pipelines.

O sistema também possui mecanismos de auditoria, particionamento de dados e rotinas automatizadas de backup.

O projeto está sendo utilizado em um ambiente real de fabricação de vidro plano no Brasil.

[Ver projeto no GitHub](https://github.com/VictorJenckel/industrial_data_gateway)
